# WUFFWERK – GitHub Pages

Repository:
https://github.com/c6wbrrs8gb-commits/wuffwerk-shop

Für ein Update:
1. `index.html` durch die Exportdatei ersetzen.
2. Auf `main` committen.
3. Settings → Pages → Deploy from a branch.
4. Branch `main`, Ordner `/ (root)`.
5. Speichern und auf die Veröffentlichung warten.

Eine eigene Domain ist nicht notwendig.
