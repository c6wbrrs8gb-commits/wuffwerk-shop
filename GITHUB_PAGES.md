# Hütepfote – Veröffentlichung mit GitHub Pages

Projektarchiv:
https://github.com/c6wbrrs8gb-commits/wuffwerk-shop

So veröffentlichst du eine Aktualisierung:
1. `index.html` durch die Exportdatei ersetzen.
2. Die Änderung auf `main` speichern.
3. In GitHub zu „Einstellungen“ → „Pages“ → „Über einen Branch bereitstellen“ wechseln.
4. Branch `main` und Ordner `/ (Stammverzeichnis)` auswählen.
5. Speichern und auf die Veröffentlichung warten.

Eine eigene Domain ist nicht notwendig.
